Komponen Komputer

1. CPU (Processor)

CPU berfungsi mengolah data dan menjalankan instruksi komputer.

2. Motherboard

Motherboard berfungsi menghubungkan seluruh komponen komputer.

3. RAM

RAM berfungsi menyimpan data sementara saat komputer digunakan.

4. HDD dan SSD

Berfungsi menyimpan data, aplikasi, dan sistem operasi.

5. Power Supply (PSU)

Berfungsi menyediakan dan menyalurkan daya listrik ke komputer.

6. VGA atau GPU

Berfungsi mengolah grafis dan tampilan gambar komputer.

7. Cooling Fan

Berfungsi membantu menjaga suhu komponen komputer.

Input dan Output

Perangkat Input (Masukan)

1. Keyboard: untuk memasukkan huruf dan angka.

2. Mouse: untuk menggerakkan kursor.

3. Microphone: untuk memasukkan suara.

4. Scanner: untuk memindai dokumen.

Perangkat Output (Keluaran)

1. Monitor: untuk menampilkan gambar.

2. Printer: untuk mencetak dokumen.

3. Speaker: untuk mengeluarkan suara.

4. Projector: untuk menampilkan gambar ke layar besar.

Cara Kerja Komputer

1. Input (Masukan)

Pengguna memasukkan data melalui keyboard, mouse, atau perangkat lainnya.

2. Process (Pemrosesan)

CPU mengolah data sesuai instruksi yang diberikan.

3. Output (Keluaran)

Komputer menampilkan hasil pengolahan melalui monitor, printer, atau speaker.

4. Storage (Penyimpanan)

Data disimpan menggunakan HDD atau SSD agar dapat digunakan kembali.
